Sitefinity and CMS

Sitefinity:

 - Sitefinity is a CMS that is designed to simplify web dev
 - Sitefinity helps drive connected experiences
 - non-technical users can use it to publish content without waiting for developers
 - handle multiple websites, languages and brands from ONE platform
 - Developer-Friendly Platform: Sitefinity is built on .NET and supports modern development frameworks like ASP.NET Core and Next.js (for headless or hybrid delivery), offering extensibility through APIs, custom modules, and widgets.
 - can be deployed on-premise or in the cloud via Sitefinity cloud
 - supports traditional, hybrid or headless delivery models
 
 - typical use cases:
	- Corporate websites and branded portals
	- Ecommerce stores
	- Intranet and extranet portals
	- Multi-site, multi-language scenarios
	- Custom applications and integrations
	
- Sitefinitiy is a web CMS meaning it itself is developed as a APS.NET web application.
 
 
 
 - a CMS platform is a software or a collection of tools and capabilities that enable you to produce, edit and organize digital content.
