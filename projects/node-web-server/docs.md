1. Install nvm, npm and node:

- [nvm repo](https://github.com/nvm-sh/nvm?tab=readme-ov-file#installing-and-updating)
- run the curl command in your terminal
- close and reopen terminal for changes to take effect
- `nvm install --lts` - installs the latest versions of node and npm
- run `node -v` and `npm -v` to check wheather you have successfuly installed node and npm

2. initialize npm in the project: `npm init`
